# Fleet silhouettes v4

Original transparent grayscale masks generated by
`tools/frontier/generate_fleet_markers.py`, dedicated under CC0-1.0.
The source generator remains under the project licence.

Landing: short broad barge, open troop bay and flat ramp. Trade: long narrow
cargo hull with three containers. Warship: larger pointed hull, bridge, two
turrets and paired barrels. The whole image receives the nation tint and rotates
together. Minimum live sizes are 18, 14 and 28 pixels respectively.

`generated.json` records hashes; `uploaded.json` records owner-hosted Roblox
uploads. `preview.png` is an asset review, not a live gameplay screenshot.
Previous masks and release tags remain available for rollback.
