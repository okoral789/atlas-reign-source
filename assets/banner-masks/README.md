# Included territory flag fills

These are compact samples of the existing 30 shop flag designs in
`assets/shop_flags/art`. They retain the original project artwork licence and
attribution; they are not newly dedicated CC0 artwork. `sources.json` records
each source file and hash. The generator is `tools/frontier/generate_banner_masks.py`.

Each 24×16 multicolor mask tiles across owned land through the existing map
compositor. Borders retain nation colors. A fill is included with its source
flag, is not sold separately, and is absent from random reward pools.
The server derives access from flag ownership and rejects a forged fill without
its flag. No extra receipt or wallet debit is created for equipping a fill.
