# Premium palette and territory patterns

Five additional exclusive country colors are appended to ProfileStyle. Historical
color indices and ownership are preserved. Shop indices select only the new
premium palette; earlier colors remain usable by their owners. A test checks
perceptual distance from the ordinary random human palette in OKLab.

Six original multicolor patterns are generated by
`tools/frontier/generate_premium_patterns.py`: Neon Circuit, Molten Rift, Royal
Filigree, Frost Prism, Nebula Grid and Tactical Contours. Existing livery IDs and
designs remain unchanged. The pattern artwork and contact sheet are dedicated
under CC0-1.0; the generator remains under the project source licence.

The game draws masks locally. Patterns retain the chosen country base color,
with fixed accent colors on marked pixels; fleet trim matches the style.
The shop uses the same live mask renderer as Customize, not image uploads.
`preview.png` shows patterns on the classic Blue color for comparison and is
not a game screenshot or an offer bundling that color with the pattern.
