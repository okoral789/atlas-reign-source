# Tactical support illustrations

`emp.png` and `fleet_repair.png` are original, code-drawn 2D equipment icons.
PNG outputs are dedicated under CC0-1.0 to the extent rights exist. Their generator,
`tools/frontier/generate_support_art.py`, remains under the program licence.
No third-party reference images, models or artwork were used.

`generated.json` records file hashes. `uploaded.json` records the actual asset IDs
and owner creator account. `preview.png` is an asset review sheet, not a game screenshot.
The same illustrations appear in the Armory catalogue, demos and unlocked HUD slots.
