# Atlas Reign UI artwork v2

Original transparent wordmark and four Armory illustrations generated with the
built-in `image_gen.imagegen` tool on 2026-11-01. The desktop OpenAI key was not used.

- [wordmark.png](wordmark.png): ivory/cyan title with compass.
- [armory-icons.png](armory-icons.png): Atom, Hydrogen, MIRV and Reinforcements.
- [generation-record.json](generation-record.json): exact prompts, source dimensions,
  read-only alpha bounds and SHA-256 hashes.
- [uploaded.json](uploaded.json): content hashes and Roblox asset IDs owned by
  Koralxok, including the 30 rehosted flag images.

The generated PNG pixels are unchanged. Runtime `UI/Artwork` crops using normalized
coordinates, so Roblox texture-resolution changes do not break sprite rectangles.
The icons are 2D UI illustrations, not 3D models or new gameplay equipment.

Flag originals remain in `assets/shop_flags/art`; their existing project provenance
and attribution in `NOTICE.md` and `docs/ASSET-AUDIT.md` are retained. Rehosting changes
asset access, not authorship or licensing. No product IDs or Robux prices changed.
