# Illustrated interface badges

Nine original code-drawn illustrations by the Atlas Reign contributor:
Customize, World Ladder, Armory, Style Shop, Help, Party, Reports, Mega Nuke
and Scattershot. Generated by `tools/frontier/generate_ui_badges.py` without
external artwork. PNG outputs are dedicated under CC0-1.0; the generator remains
under the project licence. See `licenses/CC0-1.0.txt`.

`badges.png` is a transparent 768×768 atlas with 256×256 cells. The native UI
uses proportional crops so lower-resolution Roblox copies remain usable.
`generated.json` gives cell order and hashes; `uploaded.json` gives owner-hosted
asset evidence. `preview.png` is an asset sheet, not a game screenshot.
